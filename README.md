# Den Modern — unofficial demo
A static concept for Den Modern, the vintage and modern home-goods boutique in Mendocino.
Pages: home, point of view, collections, visit, contact.
Motion: animated hero image, rotating headline, scroll reveals, moving ticker, responsive navigation, reading progress, collection filters, local-only demo form.
All imagery is illustrative stock and does not represent current store inventory. Store hours and pricing are not invented.
